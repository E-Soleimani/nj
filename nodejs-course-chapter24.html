Function Composition

Curry چیست؟

Currying یک تکنیک برنامه‌نویسی تابعی است: تابعی که چند آرگومان می‌گیرد را به زنجیره‌ای از توابع تک‌آرگومانی تبدیل می‌کنید. به جای f(a, b, c) می‌نویسید f(a)(b)(c). هر فراخوانی یک تابع جدید برمی‌گرداند که آرگومان بعدی را می‌گیرد.

چرا این کار را می‌کنیم؟ Curry به شما اجازه می‌دهد یک تابع را تدریجی پر کنید. مثلاً اگر یک تابع add(a, b) دارید، می‌توانید یک نسخه «از پیش پر شده» مثل add5 = add(5) بسازید و بعداً add5(10) صدا بزنید.

مثال ۱ — Curry دستی

curry-basic.js
// تابع معمولی — هر سه آرگومان را یکجا می‌گیرد function add(a, b, c) { return a + b + c; } console.log(add(1, 2, 3)); // 6 // همان تابع به صورت Curried — یک آرگومان در هر مرحله function curriedAdd(a) { return function(b) { return function(c) { return a + b + c; }; }; } console.log(curriedAdd(1)(2)(3)); // 6 // با arrow function خواناتر می‌شود const curriedAddArrow = a => b => c => a + b + c; console.log(curriedAddArrow(1)(2)(3)); // 6 // قدرت واقعی Curry — partial application // یک تابع را تدریجی پر می‌کنیم const add5 = curriedAddArrow(5); // منتظر b است const add5and10 = add5(10); // منتظر c است console.log(add5and10(20)); // 35

مثال ۲ — تابع Curry عمومی (helper)

به جای دستی nested function نوشتن، یک helper بسازید که هر تابعی را curry کند:

curry-helper.js
// تابع عمومی curry — هر تابعی را به نسخه curried تبدیل می‌کند function curry(fn) { return function curried(...args) { // اگر تعداد آرگومان‌های داده‌شده کافی است، تابع را اجرا کن if (args.length >= fn.length) { return fn.apply(this, args); } // در غیر این صورت، یک تابع جدید برگردان که منتظر بقیه آرگومان‌هاست return function(...moreArgs) { return curried.apply(this, [...args, ...moreArgs]); }; }; } // استفاده function multiply(a, b, c) { return a * b * c; } const curriedMultiply = curry(multiply); console.log(curriedMultiply(2)(3)(4)); // 24 console.log(curriedMultiply(2, 3)(4)); // 24 — می‌توانید چند آرگومان با هم بدهید console.log(curriedMultiply(2, 3, 4)); // 24 — یا همه را یکجا

مثال ۳ — کاربرد واقعی در Node.js

کاربرد عملی: ساخت middleware یا validatorهای قابل تنظیم برای Fastify/Express:

curry-real-world.js
// تابع curried برای validation با پیام خطای قابل تنظیم const validateRange = curry((min, max, value) => { if (value < min || value > max) { throw new Error(`مقدار باید بین ${min} و ${max} باشد`); } return true; }); // یک validator مخصوص "سن" می‌سازیم — از پیش پر شده const validateAge = validateRange(0, 120); validateAge(25); // ✅ true // validateAge(200); ← throw می‌شود // یک validator مخصوص "درصد تخفیف" const validatePercentage = validateRange(0, 100); // استفاده در Fastify schema یا middleware const ageMiddleware = (req, res, next) => { try { validateAge(req.body.age); next(); } catch (err) { res.status(400).json({ error: err.message }); } };

Function Composition — ترکیب توابع

Composition یعنی خروجی یک تابع را به ورودی تابع بعدی بدهید — مثل لوله‌کشی. به جای nested function call مثل f(g(h(x)))، یک pipeline تمیز می‌سازید.

composition.js
// compose — از راست به چپ اجرا می‌شود (مثل ریاضی: f(g(x))) const compose = (...fns) => x => fns.reduceRight((acc, fn) => fn(acc), x); // pipe — از چپ به راست اجرا می‌شود (خوانا‌تر برای اکثر افراد) const pipe = (...fns) => x => fns.reduce((acc, fn) => fn(acc), x); // توابع ساده const trim = str => str.trim(); const toLowerCase = str => str.toLowerCase(); const removeSpaces = str => str.replace(/\s+/g, '-'); // ساخت slug با pipe — خوانا و واضح const createSlug = pipe(trim, toLowerCase, removeSpaces); console.log(createSlug(' Hello World ')); // 'hello-world' // کاربرد واقعی — pipeline پردازش داده ورودی کاربر const sanitizeInput = pipe( str => str.trim(), str => str.replace(/<script>.*?<\/script>/gi, ''), // حذف اسکریپت مخرب str => str.slice(0, 500) // محدود کردن طول ); const userComment = sanitizeInput(' Hello <script>alert(1)</script> world '); console.log(userComment); // 'Hello world'
💡

Curry vs Composition: Curry روی تعداد آرگومان‌ها یک تابع کار می‌کند. Composition روی زنجیر کردن چند تابع کار می‌کند. این دو اغلب با هم استفاده می‌شوند.

نکات کلیدی برای مصاحبه

  • Curry: تبدیل تابع چند‌آرگومانی به زنجیره توابع تک‌آرگومانی — f(a,b,c) به f(a)(b)(c).
  • Partial Application: نتیجه عملی Curry — یک تابع را تدریجی پر می‌کنید و نسخه‌های تخصصی می‌سازید.
  • fn.length تعداد پارامترهای تعریف‌شده یک تابع را برمی‌گرداند — پایه helper عمومی curry.
  • compose از راست به چپ، pipe از چپ به راست اجرا می‌شود — هر دو با reduce ساخته می‌شوند.
  • کاربرد واقعی: ساخت validatorهای قابل تنظیم، pipelineهای پردازش داده، middleware factory.
  • سوال رایج: «فرق curry و partial application چیست؟» — curry همیشه یک آرگومان در هر مرحله می‌گیرد و زنجیره کامل تابع تک‌آرگومانی می‌سازد؛ partial application می‌تواند چند آرگومان با هم پر کند و بقیه را برای بعد بگذارد.
  • یک تله رایج: فکر کردن که curry فقط یک تمرین تئوریک است — در عمل در ساخت middleware قابل تنظیم و validatorهای دوباره‌قابل‌استفاده خیلی کاربردی است.
  • Pure function پایه توابع تابعی (functional) است: برای ورودی یکسان همیشه خروجی یکسان می‌دهد و هیچ side effect ندارد — این خاصیت curry و compose را قابل پیش‌بینی می‌کند.
  • در پروژه واقعی، compose/pipe اغلب برای ساخت pipeline پردازش داده استفاده می‌شود — مثلاً چند تابع تمیزکاری و اعتبارسنجی روی ورودی کاربر پشت سر هم.
