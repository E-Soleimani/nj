Prototype Chain — پشت صحنه JavaScript

در JavaScript هر object یک پدر پنهان دارد که بهش prototype می‌گویند. وقتی یک property روی object پیدا نشود، JS آن را در prototype جستجو می‌کند، بعد prototype prototype، و الی‌آخر. این زنجیر را Prototype Chain می‌گویند.

مثال ساده: وقتی می‌نویسید arr.map()، متد map روی آرایه‌ی شما نیست — روی Array.prototype است. JS آن را از prototype پیدا می‌کند.

prototype.js
// هر function یک prototype دارد function Person(name) { this.name = name; } // متد را روی prototype تعریف می‌کنیم (نه داخل constructor) // اینطوری همه instance‌ها یک نسخه از این متد دارند — صرفه‌جویی در حافظه Person.prototype.greet = function() { return `Hello, I'm ${this.name}`; }; const ali = new Person('Ali'); console.log(ali.greet()); // Hello, I'm Ali // بررسی زنجیر prototype console.log(ali.__proto__ === Person.prototype); // true console.log(Person.prototype.__proto__ === Object.prototype); // true // اضافه کردن متد به همه آرایه‌ها (anti-pattern ولی برای یادگیری خوب است) Array.prototype.sum = function() { return this.reduce((acc, n) => acc + n, 0); }; console.log([1, 2, 3].sum()); // 6

this — گیج‌کننده‌ترین مفهوم JavaScript

this در JavaScript بسته به اینکه تابع چطور فراخوانی شده، مقدار متفاوتی دارد. این یکی از رایج‌ترین منابع باگ است. باید دقیق بدانید در هر حالت this به چه چیزی اشاره می‌کند.

this-context.js
// ۱. در object method — this = آن object const user = { name: 'Ali', greet() { return `Hello ${this.name}`; // this = user } }; console.log(user.greet()); // Hello Ali // ۲. وقتی method را جدا می‌کنید — this گم می‌شود! const greetFn = user.greet; // greetFn() ← در strict mode: TypeError، در غیر strict: this = global // ۳. Arrow function — this را از scope بیرونی می‌گیرد (lexical this) class Timer { constructor() { this.seconds = 0; } start() { // ✅ arrow function — this هنوز Timer instance است setInterval(() => { this.seconds++; console.log(this.seconds); }, 1000); // ❌ regular function — this = undefined یا global setInterval(function() { // this.seconds ← خطا! }, 1000); } } // ۴. bind، call، apply — تعیین دستی this function introduce(city, country) { return `${this.name} from ${city}, ${country}`; } const person = { name: 'Sara' }; // call: فوری اجرا می‌کند، آرگومان‌ها جدا console.log(introduce.call(person, 'Tehran', 'Iran')); // apply: فوری اجرا می‌کند، آرگومان‌ها آرایه console.log(introduce.apply(person, ['Tehran', 'Iran'])); // bind: تابع جدید می‌سازد با this ثابت const saraIntroduce = introduce.bind(person); console.log(saraIntroduce('Tehran', 'Iran'));

Generator Functions — توابع مکث‌پذیر

یک تابع معمولی از اول تا آخر اجرا می‌شود. Generator می‌تواند در وسط اجرا مکث کند، یک مقدار بدهد، و بعداً از همان نقطه ادامه دهد. با علامت function* و کلمه yield تعریف می‌شود.

تشبیه: مثل یک کتاب که bookmark می‌گذارید — می‌توانید ببندید، بعداً از همان صفحه ادامه دهید.

generators.js
// تعریف generator با function* function* counter() { console.log('شروع شد'); yield 1; // مکث — مقدار 1 برمی‌گرداند console.log('ادامه داد'); yield 2; // مکث — مقدار 2 برمی‌گرداند console.log('تموم شد'); yield 3; } const gen = counter(); // هنوز اجرا نشده! console.log(gen.next()); // شروع شد → { value: 1, done: false } console.log(gen.next()); // ادامه داد → { value: 2, done: false } console.log(gen.next()); // تموم شد → { value: 3, done: false } console.log(gen.next()); // → { value: undefined, done: true } // کاربرد واقعی — تولید ID یکتا بی‌نهایت function* idGenerator() { let id = 1; while (true) { yield id++; } } const nextId = idGenerator(); console.log(nextId.next().value); // 1 console.log(nextId.next().value); // 2 console.log(nextId.next().value); // 3 // با for...of function* range(start, end) { for (let i = start; i <= end; i++) yield i; } for (const num of range(1, 5)) { console.log(num); // 1 2 3 4 5 }

Symbol — کلیدهای یکتا

Symbol نوع داده‌ای است که هر بار یک مقدار کاملاً یکتا می‌سازد. دو Symbol هیچ‌وقت با هم برابر نیستند حتی اگر همان توضیح را داشته باشند. کاربرد اصلی: ساختن property keyهایی که با کدهای دیگر تداخل نداشته باشند.

symbol.js
// هر Symbol یکتا است const id1 = Symbol('id'); const id2 = Symbol('id'); console.log(id1 === id2); // false — حتی با همان نام! // استفاده به عنوان property key const SECRET_KEY = Symbol('secretKey'); const user = { name: 'Ali', [SECRET_KEY]: 's3cr3t-t0ken' // این در JSON.stringify نمی‌آید }; console.log(user[SECRET_KEY]); // s3cr3t-t0ken console.log(JSON.stringify(user)); // {"name":"Ali"} — بدون secret! console.log(Object.keys(user)); // ['name'] — Symbol نمایش داده نمی‌شود // Well-known Symbols — تغییر رفتار پیش‌فرض class MyArray { constructor(...items) { this.items = items; } // با تعریف این، آبجکت با for...of کار می‌کند [Symbol.iterator]() { let index = 0; return { next: () => ({ value: this.items[index], done: index++ >= this.items.length }) }; } } for (const item of new MyArray(1, 2, 3)) { console.log(item); // 1 2 3 }

Proxy — نگهبان Object

Proxy یک لایه میانی (wrapper) دور یک object می‌گذارد و می‌توانید رفتار خواندن، نوشتن، حذف و سایر عملیات را دستکاری کنید. مثل یک نگهبان که هر دسترسی را کنترل می‌کند.

proxy.js
// مثال ۱ — validation خودکار function createValidatedUser(data) { return new Proxy(data, { // set: هر بار که مقداری set می‌شود اجرا می‌شود set(target, key, value) { if (key === 'age' && (typeof value !== 'number' || value < 0)) { throw new Error('Age must be a positive number'); } if (key === 'email' && !value.includes('@')) { throw new Error('Invalid email format'); } target[key] = value; return true; } }); } const user = createValidatedUser({}); user.name = 'Ali'; // ✅ user.age = 25; // ✅ user.email = 'ali@test.com'; // ✅ // user.age = -5; ← Error: Age must be a positive number // مثال ۲ — logging دسترسی‌ها const config = new Proxy({ port: 3000, host: 'localhost' }, { get(target, key) { console.log(`[Config] Reading: ${key}`); return target[key]; } }); console.log(config.port); // [Config] Reading: port // 3000

WeakMap و WeakSet

WeakMap مثل Map است ولی با یک تفاوت مهم: key‌های آن باید object باشند، و اگر به آن object دیگر هیچ reference‌ای نباشد، garbage collector آن را حذف می‌کند. این از memory leak جلوگیری می‌کند.

weakmap.js
// WeakMap — نگه داشتن داده خصوصی مرتبط با object const privateData = new WeakMap(); class BankAccount { constructor(owner, balance) { // داده خصوصی را در WeakMap ذخیره می‌کنیم privateData.set(this, { balance, transactions: [] }); this.owner = owner; } deposit(amount) { const data = privateData.get(this); data.balance += amount; data.transactions.push({ type: 'deposit', amount }); } getBalance() { return privateData.get(this).balance; } } const account = new BankAccount('Ali', 1000); account.deposit(500); console.log(account.getBalance()); // 1500 // console.log(account.balance) ← undefined — واقعاً خصوصی است!

نکات کلیدی برای مصاحبه

  • Prototype Chain: وقتی property پیدا نشود، JS در زنجیر prototype بالا می‌رود تا به Object.prototype برسد.
  • Arrow function this ندارد — this را از scope بیرونی می‌گیرد. در callback‌ها این مزیت بزرگی است.
  • bind/call/apply برای تعیین دستی this هستند. bind تابع جدید می‌سازد، call/apply فوری اجرا می‌کنند.
  • Generator برای lazy evaluation و کنترل جریان اجرا. در کتابخانه‌هایی مثل Redux-Saga استفاده می‌شود.
  • Symbol برای ساخت property keyهای یکتا که با کدهای دیگر تداخل نداشته باشند.
  • Proxy در framework‌هایی مثل Vue.js برای reactive data استفاده می‌شود.
  • سوال رایج: «this در تابع معمولی چطور تعیین می‌شود؟» — بر اساس نحوه فراخوانی تابع، نه جایی که تعریف شده؛ مثلاً obj.method() باعث می‌شود this برابر obj باشد، ولی همان تابع اگر جدا صدا زده شود، this آن تعریف‌نشده یا global است.
  • یک تله رایج: استفاده از arrow function برای متد یک class وقتی نیاز به this پویا دارید — چون arrow function this را همیشه از بیرون می‌گیرد، در بعضی موقعیت‌ها (مثل event listener) رفتار غیرمنتظره می‌دهد.
  • WeakMap برخلاف Map، اجازه می‌دهد کلیدها (که باید object باشند) توسط garbage collector جمع‌آوری شوند — برای cache یا نگه‌داری metadata بدون memory leak مفید است.
  • هر function در JavaScript خودش یک object است — یعنی می‌تواند property داشته باشد و به عنوان مقدار پاس داده شود (first-class function)؛ همین پایه‌ی callback و higher-order function‌هاست.
