RxJS
Reactive Programming

برنامه‌نویسی Reactive با Observable — مدیریت جریان‌های داده زمانی با operatorهای قدرتمند، و کاربرد آن در NestJS microservices.

ObservableOperatorsswitchMapdebounceTime

RxJS چیست؟

RxJS (Reactive Extensions for JavaScript) یک کتابخانه برای برنامه‌نویسی Reactive است — مدیریت رویدادهای async با Observable و عملگرهای ترکیبی (operators). اگر Promise یک مقدار را در آینده برمی‌گرداند، Observable می‌تواند چندین مقدار در طول زمان منتشر کند.

تشبیه: Promise مثل یک پیتزا سفارش‌دادن است — یک بار سفارش، یک بار تحویل. Observable مثل یک سرویس استریم موزیک است — مدام داده (آهنگ بعدی) می‌فرستد تا وقتی که قطع کنید.

Observable پایه

terminal
npm install rxjs
observable-basics.js
const { Observable, of, interval } = require('rxjs'); // ساخت یک Observable دستی const simpleObservable = new Observable(subscriber => { subscriber.next(1); // انتشار یک مقدار subscriber.next(2); subscriber.next(3); subscriber.complete(); // اعلام پایان }); // subscribe — مثل .then() در Promise ولی برای چند مقدار simpleObservable.subscribe({ next: value => console.log('مقدار:', value), error: err => console.error('خطا:', err), complete: () => console.log('تمام شد') }); // خروجی: مقدار: 1, مقدار: 2, مقدار: 3, تمام شد // of — ساخت سریع Observable از مقادیر ثابت of(10, 20, 30).subscribe(v => console.log(v)); // interval — هر n میلی‌ثانیه یک مقدار منتشر می‌کند (مثل setInterval) const ticker = interval(1000).subscribe(tick => console.log(`tick ${tick}`)); // بعد از 5 ثانیه متوقف کنید: setTimeout(() => ticker.unsubscribe(), 5000);

Operators — قدرت واقعی RxJS

Operators توابعی هستند که جریان داده را تبدیل، فیلتر یا ترکیب می‌کنند — شبیه map/filter آرایه، ولی برای جریان‌های زمانی:

operators.js
const { fromEvent, interval } = require('rxjs'); const { map, filter, debounceTime, take, switchMap } = require('rxjs/operators'); // map و filter — مثل آرایه ولی روی stream زمانی interval(500).pipe( map(x => x * 2), // هر مقدار را دو برابر کن filter(x => x % 4 === 0), // فقط مضرب‌های 4 take(5) // فقط 5 مقدار اول، بعد complete ).subscribe(v => console.log(v)); // مثال واقعی — debounce برای search input (در سرور هم کاربرد دارد) const { Subject } = require('rxjs'); const searchSubject = new Subject(); // هم Observable هم Observer searchSubject.pipe( debounceTime(300), // 300ms صبر کن قبل از پردازش — جلوگیری از درخواست‌های اضافه switchMap(query => searchDatabase(query)) // جستجوی قبلی را لغو کن، جدید را شروع کن ).subscribe(results => console.log('نتایج:', results)); // هر بار کاربر تایپ می‌کند: searchSubject.next('a'); searchSubject.next('al'); searchSubject.next('ali'); // فقط این پردازش می‌شود — قبلی‌ها debounce شدند

کاربرد RxJS در Node.js — NestJS Microservices

RxJS در دنیای frontend (Angular) معروف‌تر است، ولی در Node.js هم کاربرد واقعی دارد — مخصوصاً در NestJS برای ارتباطات بین سرویس‌ها و WebSocket gateways:

nestjs-rxjs-gateway.ts
import { Observable } from 'rxjs'; import { map, filter } from 'rxjs/operators'; import { SubscribeMessage, WebSocketGateway, MessageBody } from '@nestjs/websockets'; @WebSocketGateway() export class EventsGateway { // در NestJS، یک handler می‌تواند یک Observable برگرداند // به جای یک پاسخ، یک جریان پاسخ می‌فرستد @SubscribeMessage('events') handleEvent(@MessageBody() data: any): Observable<WsResponse> { return from([1, 2, 3]).pipe( map(item => ({ event: 'events', data: item })) ); // کلاینت سه پیام جدا دریافت می‌کند — یکی برای هر مقدار } } // کاربرد دیگر — ترکیب چند منبع داده async با forkJoin import { forkJoin } from 'rxjs'; function getUserDashboard(userId) { return forkJoin({ user: fetchUser(userId), // هر کدام یک Observable/Promise orders: fetchOrders(userId), reviews: fetchReviews(userId) }); // مثل Promise.all ولی با قدرت ترکیب RxJS operators }

RxJS Observable در مقابل Promise و EventEmitter

Promise

یک مقدار، یک بار

Eager — همین که می‌سازید شروع می‌شود

EventEmitter

چند مقدار، بدون operator ترکیبی

هیچ مفهوم cancel/unsubscribe ساده‌ای ندارد

Observable (RxJS)

چند مقدار، با ده‌ها operator ترکیبی

Lazy — تا subscribe نکنید شروع نمی‌شود

قابلیت لغو

Observable با unsubscribe() راحت لغو می‌شود

Promise نیاز به AbortController دارد

نکات کلیدی برای مصاحبه

  • Observable می‌تواند چند مقدار در طول زمان منتشر کند — برخلاف Promise که فقط یک بار.
  • Observable Lazy است — تا subscribe() نشود، هیچ کدی اجرا نمی‌شود.
  • Operators (map, filter, debounceTime, switchMap) جریان داده را تبدیل و ترکیب می‌کنند.
  • switchMap برای لغو خودکار درخواست قبلی هنگام شروع جدید — مهم برای search و real-time.
  • در Node.js، RxJS بیشتر در NestJS WebSocket Gateways و microservices استفاده می‌شود.
  • unsubscribe() برای جلوگیری از memory leak — همیشه subscription‌های بی‌مصرف را پاک کنید.
  • سوال رایج: «فرق Promise و Observable چیست؟» — Promise فقط یک بار resolve/reject می‌شود و بلافاصله بعد از ساخته شدن اجرا می‌شود (eager)؛ Observable می‌تواند چند مقدار بدهد و تا subscribe نشود اجرا نمی‌شود (lazy)، همچنین قابل لغو (unsubscribe) است.
  • یک تله رایج: فراموش کردن unsubscribe در یک کامپوننت یا سرویس که مدام دوباره ساخته می‌شود — subscriptionهای رها شده حافظه را اشغال نگه می‌دارند.
  • mergeMap همه درخواست‌ها را موازی نگه می‌دارد؛ switchMap فقط آخرین را نگه می‌دارد و بقیه را لغو می‌کند؛ concatMap آن‌ها را به ترتیب یکی‌یکی اجرا می‌کند.
  • Operatorها با .pipe() زنجیر می‌شوند — هر operator یک Observable جدید برمی‌گرداند، دقیقاً مثل زنجیره متدهای آرایه (map/filter).
