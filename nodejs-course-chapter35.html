ساخت یک Readable Stream سفارشی

گاهی منبع داده شما یک فایل یا شبکه نیست — مثلاً می‌خواهید داده را از یک API صفحه‌بندی‌شده، یا یک generator، یا یک منبع دلخواه به صورت stream تولید کنید. با extend کردن کلاس Readable می‌توانید منبع stream خودتان را بسازید:

custom-readable.js
const { Readable } = require('stream'); // Stream سفارشی که اعداد را یکی‌یکی تولید می‌کند class NumberStream extends Readable { constructor(max, options) { super(options); this.current = 0; this.max = max; } // _read — Node.js این متد را هر بار که به داده بیشتر نیاز دارد صدا می‌زند _read() { if (this.current < this.max) { this.current++; // push — داده را به مصرف‌کننده بفرست this.push(`${this.current}\n`); } else { this.push(null); // null یعنی: داده تمام شد } } } const numberStream = new NumberStream(5, { encoding: 'utf8' }); numberStream.pipe(process.stdout); // 1 2 3 4 5 چاپ می‌شود // کاربرد واقعی — Stream برای خروجی API صفحه‌بندی شده class PaginatedAPIStream extends Readable { constructor(apiUrl, options) { super({ ...options, objectMode: true }); // objectMode برای داده غیر-string/buffer this.apiUrl = apiUrl; this.page = 1; this.done = false; } async _read() { if (this.done) { this.push(null); return; } const response = await fetch(`${this.apiUrl}?page=${this.page}`); const { items, hasMore } = await response.json(); items.forEach(item => this.push(item)); // هر آیتم را به صورت object push کن this.page++; this.done = !hasMore; } }

ساخت یک Transform Stream سفارشی

Transform stream داده را می‌گیرد، تغییر می‌دهد و به مرحله بعد می‌فرستد — مثلاً برای فیلتر کردن، parse کردن یا تغییر فرمت در حین جریان داده:

custom-transform.js
const { Transform } = require('stream'); // Transform stream که متن را به حروف بزرگ تبدیل می‌کند class UppercaseTransform extends Transform { // _transform — برای هر chunk صدا زده می‌شود _transform(chunk, encoding, callback) { const uppercased = chunk.toString().toUpperCase(); // callback(error, data) — اولین آرگومان خطا، دومین داده تبدیل‌شده callback(null, uppercased); } } // استفاده در pipeline const fs = require('fs'); fs.createReadStream('input.txt') .pipe(new UppercaseTransform()) .pipe(fs.createWriteStream('output.txt')); // مثال واقعی — Transform که JSON خط‌به‌خط را parse می‌کند (JSONL/NDJSON) class JSONLineParser extends Transform { constructor() { super({ objectMode: true }); this.buffer = ''; } _transform(chunk, encoding, callback) { this.buffer += chunk.toString(); const lines = this.buffer.split('\n'); this.buffer = lines.pop(); // خط ناقص آخر را نگه دار for (const line of lines) { if (line.trim()) { this.push(JSON.parse(line)); // هر خط را parse کن و push کن } } callback(); } }

Generators — Stream ساده‌تر با Syntax مدرن

یادتان هست در فصل Advanced JS با Generator آشنا شدیم؟ از Node.js نسخه ۱۲ به بعد، می‌توانید مستقیماً از async generator function به جای کلاس Readable استفاده کنید — کد بسیار کوتاه‌تر می‌شود:

generator-as-stream.js
const { Readable } = require('stream'); // async generator function — به جای کلاس کامل Readable async function* generateNumbers(max) { for (let i = 1; i <= max; i++) { await new Promise(r => setTimeout(r, 100)); // شبیه‌سازی تاخیر yield `${i}\n`; } } // Readable.from — یک generator را به stream تبدیل می‌کند! const stream = Readable.from(generateNumbers(5)); stream.pipe(process.stdout); // همین الگو برای Transform هم کار می‌کند — با generator زنجیر کنید async function* filterEven(source) { for await (const chunk of source) { const num = Number(chunk.toString().trim()); if (num % 2 === 0) yield `${num}\n`; } } const { pipeline } = require('stream/promises'); await pipeline( Readable.from(generateNumbers(10)), filterEven, // generator function مستقیم در pipeline process.stdout ); // فقط اعداد زوج چاپ می‌شوند: 2 4 6 8 10
💡

چرا Generator بهتر است؟ دیگر نیازی به مدیریت دستی _read، push(null) یا callback نیست. کد generator خیلی شبیه یک حلقه معمولی است — خواناتر و کمتر خطاپذیر.

نکات کلیدی برای مصاحبه

  • برای منبع stream سفارشی، از Readable extend کنید و متد _read را implement کنید.
  • push(null) یعنی stream تمام شده — Node.js دیگر منتظر داده بیشتر نمی‌ماند.
  • برای Transform، متد _transform(chunk, encoding, callback) را implement کنید.
  • objectMode: true وقتی داده شما string/buffer نیست — مثلاً object‌های JS.
  • Readable.from(generator) ساده‌ترین راه تبدیل یک async generator به stream است.
  • Generator functionها می‌توانند مستقیماً در pipeline() به عنوان Transform استفاده شوند.
  • سوال رایج: «چرا generator ساده‌تر از کلاس Readable سفارشی است؟» — دیگر نیازی به مدیریت دستی push/pull یا callback نیست؛ کد generator شبیه یک حلقه معمولی است و خواناتر.
  • یک تله رایج: فراموش کردن push(null) در پایان کار — Node.js فکر می‌کند هنوز داده بیشتری در راه است و stream هیچ‌وقت 'end' نمی‌شود.
  • Generator با کلمه کلیدی yield یک مقدار را «موقتاً» برمی‌گرداند و اجرای تابع را متوقف می‌کند تا دفعه بعد ادامه یابد — این پایه lazy evaluation در جاوااسکریپت است.
  • Async Generator (با async function*) هم yield می‌دهد هم await می‌کند — برای منابع داده‌ای که هم async هستند هم چندتایی (مثل صفحه‌بندی API) بسیار مناسب است.
